## 三、获客引擎

### 内容获客 Agent

```
平台矩阵:
  小红书: 每日 3 篇（疗愈故事 + 金句 + 测评引流）
  抖音: 每日 1 条（15-60s 情感语录 + 真实案例）
  视频号: 每日 1 条（导师直播切片 + 学员分享）
  公众号: 每日 1 篇（深度疗愈文章 + 课程预告）

Agent 工作流:
  ① 选题生成: 基于热点 + 搜索趋势 → 每日 10 个选题
  ② 内容生成: AI 生成文案/脚本/字幕
  ③ 自动发布: 定时发布到各平台
  ④ 互动运营: AI 自动回复评论 + 私信引导小程序
  ⑤ 数据追踪: 每篇内容的曝光/互动/转化
```

### 免费测评 Agent

```
测评类型:
  · 依恋风格测试（情感类）
  · 家庭关系健康度（家庭类）
  · 创业者焦虑指数（创业类）
  · 能量频率检测（智慧疗愈类）

Agent 工作流:
  ① 用户扫码 → 进入测评（5 分钟, 10-15 题）
  ② AI 即时生成测评报告（个性化 + 专业性）
  ③ 报告末尾: "你的疗愈师正在等你" → 引导预约
  ④ 自动收集手机号 → 进入 CRM
```

### 裂变 Agent

```
裂变机制:
  · 测评报告分享 → "我也测了, 来看看你的"
  · 邀请好友测评 → 双方各得 1 次免费轻咨询
  · 付费后分享专属海报 → 好友购买得 20% 佣金
  · 打卡分享: 每日疗愈打卡 → 朋友圈传播
```

## 四、转化成交引擎

### 四级漏斗

```
流量层 (免费)
  │  小红书/抖音内容 → 小程序 → 免费测评
  │  转化率: 内容 → 测评 = 15%
  ▼
体验层 (¥9.9-99)
  │  免费测评 → 低价体验（15min 轻咨询 / 1 节体验课）
  │  转化率: 测评 → 体验 = 25%
  ▼
付费层 (¥199-1,999)
  │  体验满意 → 正式疗程 / 深度咨询
  │  转化率: 体验 → 付费 = 40%
  ▼
长期层 (¥2,000+)
  │  付费满意 → 年卡 / 会员 / 线下工作坊
  │  转化率: 付费 → 长期 = 20%
```

### 转化 Agent

```yaml
自动化 SOP:
  Day 0: 用户完成测评 → 推送结果 + 匹配导师
  Day 1: 未预约 → 推送案例故事（与用户相似的人）
  Day 3: 未预约 → 推送限时优惠（首单 5 折）
  Day 7: 未预约 → 推送免费直播预告
  Day 14: 仍未转化 → 降频推送（每月 1 次）
```

## 五、导师入驻引擎

### 入驻流程

```
导师申请 → AI 初审 → 人工终审 → 签约 → 培训 → 上线

Agent 工作流:
  ① 资质审核: AI 验证证书照片 + 学历 + 从业年限
  ② 能力评估: 模拟咨询（AI 扮演客户 → 导师应答 → AI 评分）
  ③ 背景调查: 公开信息检索（负面/纠纷/诉讼）
  ④ 签约: 电子合同 + 电子签名
  ⑤ 培训: AI 推送平台规则 + 话术培训 + 工具使用
  ⑥ 上线: 分配初始流量 + 导师专属主页
```

### 导师分层

| 等级 | 条件 | 分成 | 流量分配 |
|------|------|------|---------|
| **实习导师** | 入驻 < 30 天, 服务 < 20 单 | 60% | 新客户池 |
| **认证导师** | 服务 ≥ 50 单, 好评率 ≥ 95% | 70% | 精准匹配 |
| **资深导师** | 服务 ≥ 200 单, 复购率 ≥ 60% | 80% | 优先推荐 |
| **明星导师** | 服务 ≥ 500 单, 学员推荐 ≥ 100 | 85% | 首页 + 专栏 |

### 自动分配引擎

```
客户需求 → 导师匹配:
  ① 问题类型（情感/家庭/创业/疗愈）→ 匹配专业方向
  ② 价格预算 → 匹配对应等级
  ③ 沟通偏好（温柔/犀利/理性/感性）→ 匹配风格
  ④ 时间偏好（工作日/周末, 上午/下午/晚上）→ 匹配可用时段
  ⑤ 往期评价 → 优先高评分导师

算法:
  匹配分 = 专业匹配 × 0.4 + 风格匹配 × 0.2 + 时间匹配 × 0.2 + 评分 × 0.2
  取 TOP 3 → 展示给客户 → 客户选择
```

## 六、客户交付引擎

### 服务类型

| 类型 | 时长 | 形式 | 交付 |
|------|------|------|------|
| **轻咨询** | 15-30min | 文字/语音/视频 | 即时预约 + 在线沟通 |
| **深度咨询** | 60min | 视频 1v1 | 预约 + 课前问卷 + 课后作业 |
| **疗程包** | 4-12 次 | 视频 + 作业 + 社群 | 每周 1 次 + 每日打卡 |
| **社群陪伴** | 30 天 | 微信群 + 直播 | 每日内容 + 每周答疑 |
| **线下工作坊** | 1-3 天 | 面对面 | 场地 + 物料 + 住宿 |

### 自动交付 Agent

```yaml
服务前:
  -1h:  自动推送提醒（时间 + 链接 + 准备事项）
  -30min: 推送课前问卷（今日状态 / 想解决的问题）
  -5min:  推送会议链接

服务中:
  实时记录: AI 语音转文字 + 关键点标记
  情绪检测: AI 分析客户语音情绪（紧张/放松/哭泣）
  作业生成: 基于咨询内容 → AI 自动生成课后作业

服务后:
  +5min:  推送课后反馈表（满意度 + 收获 + 建议）
  +1h:    推送 AI 生成的咨询摘要（ "今天我们聊了…" ）
  +1d:    推送课后作业提醒
  +3d:    检查作业提交 → 未提交自动追问
  +7d:    推送下周预约链接
```
