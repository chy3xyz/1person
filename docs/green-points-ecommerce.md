# 绿色积分电商平台 · 涨价共识自动化运营体系

> 绿色积分 = 限量通缩 + 涨价共识 + 节点裂变。
> 报单品购买 → 共识节点招募 → 代理拓展 → 流通品推广 → 积分价值叙事全自动。

## 一、核心代币经济

### 绿色积分（GP — Green Point）

| 属性 | 值 |
|------|-----|
| 名称 | Green Point |
| 符号 | GP |
| 总量 | 2.1 亿 GP（对标 BTC 总量） |
| 发行 | 零预挖。全部通过行为挖矿产出 |
| 减产 | 每 1 年减半（第一年 1 亿，第二年 5000 万...） |
| 通缩 | 每次链上交易销毁 0.5% GP |
| 质押 | 锁定 GP 获得节点身份 + 投票权 |

### 涨价共识模型

```
GP 发行速度 ∝ 1 / 时间  （指数衰减）
GP 销毁速度 ∝ 交易量    （线性增长）
→ 流通量持续萎缩
→ 稀缺性递增
→ 价格自然上涨（共识驱动）
```

**故事线**：GP 是人类对地球的"碳债务赎罪券"。每一个 GP 代表一单位被保护的自然资源。越早持有 GP 的人 = 越早参与地球修复 = 收益越大。

## 二、四层身份体系

```
Layer 4: 生态节点 (Ecological Node)
  · 持有 ≥ 100,000 GP（锁仓 3 年）
  · 权利: 提案投票 + 生态基金分配 + 审计
  · 义务: 年度生态报告 + 社区治理参与
  · 收益: 全网交易费 5% 分红

Layer 3: 代理节点 (Agent Node)
  · 持有 ≥ 10,000 GP（锁仓 1 年） + 直推 ≥ 50 人
  · 权利: 下级分润 + 区域代理权
  · 义务: 每月推广 ≥ 10 个新用户
  · 收益: 直推佣金 10% + 间推佣金 3%

Layer 2: 共识节点 (Consensus Node)
  · 购买报单品 ≥ ¥980 → 获得 100 GP（锁仓 90 天）
  · 权利: 邀请返佣 + 流通品折扣
  · 义务: 完成新手任务（推广 3 人）
  · 收益: 直推佣金 5%

Layer 1: 普通用户 (User)
  · 免费注册 → 获得 1 GP 新人奖励
  · 权利: 购买流通品 + 每日签到
  · 收益: 签到/消费/分享 得 GP
```

### 报单品 = 涨价的燃料

```
用户购买报单品 → 平台收入 ¥X
  ├── 30% → 生态基金（GP 回购销毁）
  ├── 30% → 节点分润（上层代理 + 生态节点）
  ├── 20% → 运营成本
  └── 20% → 平台利润

每次回购销毁 → GP 流通量减少 → 单价上升 → 更多人 FOMO 买入 → 循环
```

## 九、收入模型

### 单节点模型

```
1 个代理节点（¥9,800 代理包）
  ├── 招募 50 个共识节点（¥980 × 50 = ¥49,000）
  │     └── 代理节点分润: ¥49,000 × 10% = ¥4,900
  ├── 每个共识节点推广 3 个用户
  │     └── 代理节点间推: 50 × 3 × ¥980 × 3% = ¥4,410
  └── 流通品消费分润: 50 × 3 × ¥200/月 × 1% = ¥300/月

代理节点总收入: ¥9,310（一次性） + ¥300/月（持续）
```

### 平台收入

```
1000 个代理节点 × ¥9,800 = ¥9,800,000
1000 × 50 共识节点 × ¥980 = ¥49,000,000
流通品月 GMV: 150,000 用户 × ¥200 = ¥30,000,000/月
平台抽成: ¥30,000,000 × 5% = ¥1,500,000/月

一次性收入: ¥58,800,000
月持续收入: ¥1,500,000
```

## 十二、结论

绿色积分电商平台 = **限量通缩代币 + 涨价共识叙事 + 四层节点裂变 + 流通品价值锚定**。

核心壁垒：
- **减产销毁模型**天然制造稀缺 → 价格只涨不跌的数学基础
- **四层身份**绑定持有量 → 越多人买报单品 = 越多 GP 被锁仓 = 流通量越少 = 价格越高
- **5 Agent 矩阵**全自动运营涨价叙事 → 不需要人工维持共识
- **1person 9 模块直接复用** → 只需新增 5 个业务模块

**5 周**从零到 1000 代理节点，¥5800 万一次性 + ¥150 万/月持续收入。
