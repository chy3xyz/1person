1Person CLI は、Web UI でできるほぼすべての操作をそのまま提供します（[イシュー](/issues)の作成、[エージェント](/agents)の割り当て、[デーモン](/daemon-runtimes)の起動など）。このページでは、すべてのトップレベルコマンドを 1 行の説明とともに一覧します。フラグや例の完全な一覧は `1person <command> --help` を実行してください。

## 認証する

CLI を初めて使うときにこのコマンドを実行して、**パーソナルアクセストークン（PAT）**を取得します。

```bash
1person login
```

ブラウザが自動的に開きます。Web アプリで承認すると、CLI が PAT（`1p_` プレフィックス付き）を `~/.config/1person/config.json` に保存します。これ以降のすべてのコマンドはこの PAT で認証されます。

<Callout type="tip">
CI やヘッドレス環境では、ブラウザフローをスキップできます。Web アプリの **Settings → Personal Access Tokens** で PAT を作成し、`1person login --token <1p_...>` で直接渡してください。
</Callout>

トークンの種類による違いについては、[認証とトークン](/auth-tokens)を参照してください。

## 認証とセットアップ

| コマンド | 用途 |
|---|---|
| `1person login` | ログインして PAT を保存 |
| `1person auth status` | 現在のログイン状態、ユーザー、ワークスペースを表示 |
| `1person auth logout` | ローカルの PAT を削除 |
| `1person setup cloud` | 1Person Cloud のワンショットセットアップ（ログイン + デーモンのインストール） |
| `1person setup self-host` | セルフホストバックエンドのワンショットセットアップ |

## ワークスペースとメンバー

| コマンド | 用途 |
|---|---|
| `1person workspace list` | アクセスできるすべてのワークスペースを一覧 |
| `1person workspace get <slug>` | 1 つのワークスペースの詳細を表示 |
| `1person workspace member list` | 現在のワークスペースのメンバーを一覧 |
| `1person workspace update <id> --name "..." [--description "..."] [--context "..."] [--issue-prefix "..."]` | ワークスペースのメタデータを更新（admin/owner）。長いフィールドは `--description-stdin` / `--context-stdin` を使用できます。 |

## イシューとプロジェクト

<Callout type="info">
`list` 系のコマンド（`1person issue list`、`autopilot list`、`project list` など）は、デフォルトで短く**そのままコピー＆ペーストできる** ID を出力します。イシューは `MUL-123` のようなイシューキー、それ以外のリソースは短い UUID プレフィックスです。以下の後続コマンドの `<id>` 引数は短い ID と完全な UUID のどちらも受け取るため、一般的な流れは `1person issue list` → キーをコピー → `1person issue get MUL-123` となります。正式な UUID が必要なときは `list` コマンドに `--full-id` を渡してください。
</Callout>

| コマンド | 用途 |
|---|---|
| `1person issue list` | イシューを一覧（コピー＆ペーストできるイシューキーを出力） |
| `1person issue get <id>` | 単一のイシューを表示（イシューキーまたは UUID を受け取る） |
| `1person issue create --title "..."` | 新しいイシューを作成 |
| `1person issue update <id> ...` | イシューを更新（ステータス、優先度、担当者など） |
| `1person issue assign <id> --agent <slug>` | エージェントに割り当て（即座にタスクをトリガー） |
| `1person issue status <id> --set <status>` | ステータス変更のショートカット |
| `1person issue search <query>` | キーワード検索 |
| `1person issue runs <id>` | イシュー上のエージェント実行を表示 |
| `1person issue rerun <id>` | イシューの現在のエージェント担当者向けに新しいタスクを再キューイング |
| `1person issue comment <id> ...` | ネスト: コメントの表示 / 投稿 |
| `1person issue subscriber <id> ...` | ネスト: 購読 / 購読解除 |
| `1person project list/get/create/update/delete/status` | プロジェクトの CRUD |

## エージェントとスキル

| コマンド | 用途 |
|---|---|
| `1person agent list` | ワークスペースのエージェントを一覧 |
| `1person agent get <slug>` | エージェントの構成を表示 |
| `1person agent create ...` | エージェントを作成 |
| `1person agent update <slug> ...` | エージェントを更新 |
| `1person agent archive <slug>` | アーカイブ |
| `1person agent restore <slug>` | アーカイブ済みのエージェントを復元 |
| `1person agent tasks <slug>` | エージェントのタスク履歴を表示 |
| `1person agent skills ...` | ネスト: スキルのアタッチ / デタッチ |
| `1person skill list/get/create/update/delete` | スキルの CRUD |
| `1person skill import ...` | GitHub、ClawHub、またはローカルマシンからスキルをインポート |
| `1person skill files ...` | ネスト: スキルのファイルを管理 |

### スキルインポートの競合

`1person skill import --url <url>` の既定値は `--on-conflict fail` です。同じ名前のスキルがすでに存在する場合、コマンドは構造化された `conflict` 結果で終了し、ワークスペースは変更されません。

既存スキルの作成者で、スキル ID とエージェントの紐付けを維持したまま内容を置き換える場合は `--on-conflict overwrite` を使います。既存スキルを残してコピーを取り込む場合は `--on-conflict rename` を使うと、`-2` のような接尾辞が自動で付きます。同名の項目を単に飛ばす場合は `--on-conflict skip` を使います。

```bash
1person skill import --url https://skills.sh/acme/repo/review-helper
1person skill import --url https://skills.sh/acme/repo/review-helper --on-conflict overwrite
1person skill import --url https://skills.sh/acme/repo/review-helper --on-conflict rename
1person skill import --url https://skills.sh/acme/repo/review-helper --on-conflict skip
```

## スクワッド

| コマンド | 用途 |
|---|---|
| `1person squad list` | ワークスペースのスクワッドを一覧 |
| `1person squad get <id>` | 単一のスクワッドを表示 |
| `1person squad create --name "..." --leader <agent>` | スクワッドを作成（owner / admin） |
| `1person squad update <id> ...` | 名前、説明、指示、リーダー、またはアバターを更新 |
| `1person squad delete <id>` | アーカイブ（ソフト削除） — 割り当て済みのイシューをリーダーに移管 |
| `1person squad member list/add/remove <squad-id>` | スクワッドメンバーを管理 |
| `1person squad activity <issue-id> <action\|no_action\|failed> --reason "..."` | スクワッドリーダーエージェントがターンごとに評価を記録するために使用 |

完全なモデルについては[スクワッド](/squads)を参照してください。

## デーモンとランタイム

| コマンド | 用途 |
|---|---|
| `1person daemon start` | デーモンを起動（デフォルトはバックグラウンド。`--foreground` を追加するとフォアグラウンドで実行） |
| `1person daemon stop` | デーモンを停止 |
| `1person daemon restart` | デーモンを再起動 |
| `1person daemon status` | デーモンがオンラインかどうかと同時実行数を確認 |
| `1person daemon logs` | デーモンのログを表示 |
| `1person runtime list` | 現在のワークスペースのランタイムを一覧 |
| `1person runtime usage` | リソース使用量を表示 |
| `1person runtime activity` | 最近のアクティビティログ |
| `1person runtime update <id> ...` | ランタイムの構成を更新 |

## 完全なフラグを確認する

すべてのコマンドが `--help` をサポートしています。

```bash
1person issue create --help
1person agent update --help
```

v2 では、各コマンドごとに専用の詳細なリファレンスページを提供する予定です。
